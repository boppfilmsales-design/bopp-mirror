🔄 GitHub Actions 自动同步

配置 GitHub Token 后，点击"立即同步"按钮，后台数据会自动同步到 seed_data.js 并推送到线上

获取方式：GitHub → Settings → Developer settings → Personal access tokens → Generate new token
权限：repo (完整控制), workflow (管理 workflow)

📊 同步日志

暂无同步记录

📖 使用说明

  1. 在后台编辑产品/内容，点击"保存"
  2. 回到"自动同步"页面，点击"立即同步"
  3. 系统会自动：
    • 读取 localStorage 中的最新数据
    • 触发 GitHub Actions 更新 seed_data.js
    • 自动推送到 GitHub
    • Cloudflare Pages 自动重新构建
  4. 等待 1-2 分钟，前端自动更新

注意：首次使用需要配置 GitHub Token，Token 只保存在您的浏览器 localStorage 中，不会上传到任何服务器。
