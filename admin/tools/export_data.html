📤 数据同步工具

将后台编辑的数据合并到 seed_data.js 并推送到线上

步骤 1: 检查待同步数据

步骤 2: 生成合并脚本

点击下方按钮，生成一个 Python 脚本，用于合并数据

步骤 3: 运行合并脚本

在浏览器控制台运行生成的脚本，或手动操作：

  1. 下载生成的 Python 脚本
  2. 运行: python merge_overrides.py
  3. 脚本会自动更新 seed_data.js
  4. 然后执行: git add -A && git commit -m "sync overrides" && git push

步骤 4: 验证

推送后等待 1-2 分钟，访问产品页面验证更新
